第六章 函数
6.1 引用形参什么时候应该是常量引用？如果形参是常量引用，而我们将其设为普通引用，会发生什么情况
我的回答：当形参不需要改变时使用常量引用，如果应该是常量引用，而我们设为普通引用，会导致右值无法传入

补充:为什么普通引用不能接受右值:const int& r=10相当于先执行int temp=10;const int& r=temp,若使用
普通引用，会导致程序能修改临时值，这是一种非常危险的行为。

6.2 在范围for循环中使用initializer_list对象时，应该将循环控制变量声明为引用类型吗？为什么

我的答案：initializer_list对象的元素是常量，就算使用引用也无法修改里面的元素。加上其对象
都是使用int double等轻量级的类型，不涉及自定义的类，因此不需要使用引用

6.3 什么情况下返回的引用无效，什么情况下返回的常量引用无效
我的答案:返回局部变量的引用时引用无效，返回的是临时对象/局部常量时常量引用失效
正确答案以及原因:
例子:
引用无效：
1.返回局部变量的引用
int& bad_func()
{
int x=10;
return x; //错误: x是局部变量，函数结束后x被销毁，引用无效。
}
2.返回动态分配内存的指针转化的引用，但内存被提前释放
int* p=new int(5);
int& ref=*p;
delete p;
//此时ref绑定的对象已被释放，引用无效
常量引用无效：
const int& bad_const_func()
{
const int x=10;
return x;//错误: x是局部常量，函数结束后x被销毁，引用无效
}
问题: 常量引用不是可以传右值吗
答: 当你把右值绑定到const T&时，C++会把这个临时变量生命周期延长到和引用一样长, 而局部变量的生命周期无法被延长

6.4 说明在下面的每种声明中第二条声明语句是何含义，如果有非法的声明，请指出
int get();
double get();
仅凭改变返回值无法定义重载函数

第七章 类
7.1 参数列表后接const的作用
1.在这个函数内部，不能修改任何成员变量
2.const对象只能调用带末尾const的成员函数

7.2 在C++11新标准中, 如果我们需要默认构造函数，那么可以在参数列表后面加上”=default”来要求生成默认构造函数
如果已经定义了构造函数，编译器不会再自动生成默认构造函数

7.3 封装是何含义？它有什么作用
我的答案: 封装是把一个类的内部实现细节隐藏，并暴露出一些公共接口，来供用户使用

第四章 表达式
1.如果表达式求值结果是左值，decltype作用于表达式(不是变量)得到一个引用类型(int* p,解引用结果是左值，decltype(q)=int& )
2.如果表达式求值结果是右值，decltype作用与表达式是原来的类型(int p,取地址结果是右值，decltype(&q)=int** )

图片4.2

3.说明在逻辑与，逻辑或及相等性运算符中运算对象求值顺序
逻辑与：严格从左到右求值，支持短路
1.先算左侧表达式
2.如果左侧结果为false，直接判定整个表达式为false，右侧完全不执行(短路)
3.只有左侧为true，才会去计算右侧
逻辑或：严格从左到右求值，支持短路
1.先算左侧表达式
2.如果左侧结果为true，直接判定整个表达式为true，右侧完全不执行(短路)
3.只有左侧为false，才会去计算右侧
相等性运算符==，!=
没有规定求值顺序，两边运算对象都会求值，不存在短路机制
4.条件运算符(?:)
如果条件运算符满足左结合律，grade<60?”fail”:grade<75?”low pass”:grade<90?”pass”:”high pass”
若从左向右计算，如果grade<60,显示fail，否则显示grade<75,是一个bool值

2.举一个形参应该是引用类型的例子，再举一个形参不能是引用的例子

{
int temp=a;
a=b;
b=temp;
}

{
return a*2;
}
3.尽量使用常量引用
把函数不会改变的形参定义成普通引用是一种比较常见的错误，使用引用而非常量引用也会极大地限制函数所能接受的实参类型，我们不能

1.四种权限修饰符的含义

private:表示只有本类对象可以调用
空着:表示只有本包下的类对象使用
protected:表示不同包的子类可以访问
public:表示所有类都可以访问

2.静态代码块的作用以及应用场景

在{}之前加上static修饰，表示该代码块只调用一次。比如要在构造方法前打印一句话，而且只
打印一次，就可以使用静态代码块

补充：场景：用来做类的初始化，比如加载配置文件，初始化静态常量，只需执行一次的操作

3.抽象类如何定义以及特点

抽象类定义时要加上abstract关键字，另外有抽象方法的类一定是抽象类，但抽象类不一定有抽象
方法

补充：抽象类不能new创建对象
      子类继承抽象类，必须重写全部抽象方法，否则子类也要声明为abstract抽象类
      抽象类可以拥有普通成员变量，普通方法，构造器

4.抽象类和抽象方法的意义(为什么不直接在子类中定义方法)

抽象类提供了抽象方法供子类重写，如果在子类中定义方法，达不到多态的效果，无法做到同一对象
有多种不同状态

5.接口定义出来是为了解决什么问题，以及与抽象类的区别

接口定义出来是为了给子类提供一些可重写的方法，逻辑上表示子类之间的一些具有相似之处的行为
而抽象类提供的重写方法是覆盖所有子类，供所有子类重写的，而接口的出现是为了解决子类之间部分
相同的行为，并为其提供重写方法

补充：接口和抽象类区别
1.关键字：抽象类abstract class；接口：interface
2.继承：类只能继承一个抽象类，类可以实现多个接口
3.构造方法：抽象类有构造方法，接口没有构造方法
4.成员变量：抽象类可以普通变量，接口变量默认public static final常量

6.接口中成员的特点(从成员变量，构造方法，成员方法角度)
补充：
1.成员变量：接口变量默认public static final常量
2.构造方法：接口没有构造方法，不能实例化对象
3.成员方法：JDK7：全部默认public abstract抽象方法，没有方法体
JDK8：default默认方法(需要实现类重写或直接使用)；static静态方法，接口名直接调用
JDK9：允许private私有方法，给接口内部复用

7.如果一个类运用两个接口，且两个接口的方法名一样，会发生什么

1.如果两个接口都是抽象方法：实现类只需要重写一次该方法，同时满足两个接口的要求
2.如果两个接口存在default默认方法重名，实现类必须手动重写这个冲突方法，否则报错

8.接口方法名前加一个default是什么含义

表示接口的这个方法是普通的方法,不提供重写❌

default：默认方法，带有方法体
实现类可以直接使用，也可以选择重写、
作用：接口升级时，给旧接口增加新方法，不需要所有实现类全部重写，解决接口扩展兼容问题

9.接口为什么要定义私有方法

接口定义私有方法是为了不让其他成员访问❌

接口内部多个default默认方法之间有重复代码，把重复逻辑抽取成private私有方法，只能接口内部调用
，对外隐藏，实现代码复用，不暴露给实现类
